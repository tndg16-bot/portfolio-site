## ⚙️ 自動化システム詳細

### GitHub Actionsワークフロー

#### 1. Daily Blog Post & Rebuild（メイン）

**ファイル**: `.github/workflows/daily-blog-post.yml`

**機能**:
- 毎日午前9時（JST）に自動実行
- 次の記事を特定（日付ベース：2026-01-01からの経過日数）
- 記事の日付を今日に更新
- GitHubにコミット・プッシュ
- Vercelに自動デプロイ

**実行タイミング**:
```yaml
on:
  schedule:
    - cron: '0 0 * * *'  # UTC 00:00 = JST 09:00
  workflow_dispatch:       # 手動実行も可能
```

**ロジック**:
```
1. 今日の日付取得
2. 2026-01-01からの経過日数を計算
3. 対応する記事番号を特定（例：50日目 → 051）
4. 記事ファイルを検索
5. 日付を更新
6. GitHubにコミット
7. Vercelにデプロイ
```

#### 2. Batch Schedule（バッチ予約）

**ファイル**: `.github/workflows/batch-schedule.yml`

**機能**:
- 複数記事を一括で日付設定
- 開始日と範囲を指定

**使い方**:
```yaml
# 入力パラメータ
start_number: 105    # 開始記事番号
end_number: 200      # 終了記事番号
start_date: "2026-02-01"  # 開始日
```

### 公開スケジュール

| 開始日 | 終了予定 | 総日数 | 1日あたり |
|--------|----------|--------|-----------|
| 2026-01-01 | 2026-11-15 | 320日 | 1記事/日 |

**公開例**:
- Day 1 (1/1): 001番
- Day 2 (1/2): 002番
- ...
- Day 320 (11/15): 320番

## 🔄 残タスク（Phase 5-6）

### Phase 5: 品質向上・最適化（優先度：高）

#### 5-1. カテゴリ名の統一（重要）
**問題**: カテゴリ名に重複あり
- "思考法" と 思考法（引用符の違い）
- "メンタルモデル" と メンタルモデル

**対応**:
```bash
# 一括置換スクリプト
find content/blog -name "*.md" -exec sed -i 's/category: "思考法"/category: 思考法/g' {} \;
find content/blog -name "*.md" -exec sed -i 's/category: "メンタルモデル"/category: メンタルモデル/g' {} \;
```

**工数**: 30分

#### 5-2. 日付フォーマット統一
**問題**: 日付の引用符が混在
- `date: "2026-01-01"`（ダブルクォート）
- `date: '2026-01-01'`（シングルクォート）

**対応**:
```bash
find content/blog -name "*.md" -exec sed -i "s/date: '/date: \"/g" {} \;
find content/blog -name "*.md" -exec sed -i "s/'$/\"/g" {} \;
```

**工数**: 20分

## 🔧 トラブルシューティング

### 問題: 記事が公開されない

**確認手順**:
1. GitHub Actionsタブを開く
2. 「Daily Blog Post & Rebuild」の最新実行を確認
3. 赤い×マークがあればログを確認

**よくある原因**:
- ファイルが見つからない（番号ミス）
- Gitの権限エラー
- Vercelのデプロイ失敗

### 問題: サイトが更新されない

**対策**:
1. Vercel Dashboardを開く
2. Deploymentsタブで最新のデプロイを確認
3. 手動でRedeployを実行

### 問題: 特定の記事を即公開したい

**対策**:
```bash
# 該当ファイルの日付を今日に変更
sed -i "s/date: .*/date: '$(date +%Y-%m-%d)'/" content/blog/XXX-slug.md
git add . && git commit -m "Publish article XXX" && git push
```
