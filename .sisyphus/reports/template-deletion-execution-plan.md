**パターン**:

## 🚀 削除実行

### Step 1: バックアップ作成

```bash
git add .
git commit -m "Backup: Before template deletion (fix-2, fix-3, fix-4 completed)"
```

### Step 2: テンプレートファイルの削除

```bash
cd content/blog

# 4桁数字で始まるファイルを削除
ls *.md | grep -E "^[0-9]{4,}" | xargs rm -f

# --を含むファイルを削除
ls *.md | grep "\-\-" | xargs rm -f

# 確認
ls *.md | wc -l
# 結果: 117件であることを確認
```
