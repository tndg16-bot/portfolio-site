# Google Search Console 登録ガイド

## 📌 概要

本山貴裕のポートフォリオサイトをGoogle Search Consoleに登録し、SEOパフォーマンスを監視するためのガイド。

**作成日**: 2026-01-30
**担当**: PM (Sisyphus)
**サイトURL**: https://takahiro-motoyama.vercel.app

---

## 🎯 登録の目的

Google Search Consoleに登録することで以下のメリットがあります：

1. **検索パフォーマンスの監視**: どの検索クエリで表示されているかを確認
2. **インデックス状況の確認**: どのページがインデックスされているか
3. **エラーの検知**: クロールエラーやインデックス問題を早期発見
4. **SEO改善の基礎**: Googleにサイトの存在を通知

---

## 📝 登録手順

### Step 1: Google Search Consoleにアクセス

1. [Google Search Console](https://search.google.com/search-console)にアクセス
2. Googleアカウントでログイン

### Step 2: プロパティを追加

1. 「リソースを追加」をクリック
2. 「URLプレフィックス」を選択
3. サイトURLを入力: `https://takahiro-motoyama.vercel.app`
4. 「続行」をクリック

### Step 3: 所有権の確認

**方法A: HTMLタグ（推奨）**

1. 「HTMLタグ」タブを選択
2. メタタグをコピー
3. `src/app/layout.tsx` または `src/app/head.tsx` に追加

```tsx
// src/app/layout.tsx
export const metadata = {
  verification: {
    google: 'ここにverificationコードを貼り付け',
  },
}
```

4. 「検証」をクリック

**方法B: DNS TXT（代替）**

1. Vercelダッシュボードにアクセス
2. 設定 → ドメイン → DNS設定
3. 新しいTXTレコードを追加
4. 提供されたGoogle verification codeを追加

### Step 4: サイトマップの登録

1. Google Search Consoleのダッシュボードに戻る
2. 「サイトマップ」をクリック
3. サイトマップのURLを入力: `sitemap.xml`
4. 「送信」をクリック

**サイトマップの構造**:
```
https://takahiro-motoyama.vercel.app/sitemap.xml
```

### Step 5: インデックスのリクエスト（オプション）

新しいページを公開した場合：

1. 「URL検査」をクリック
2. ページURLを入力
3. 「インデックス登録をリクエスト」をクリック

---

## ✅ 登録後の確認

### サイトマップのステータス

1. 「サイトマップ」タブに移動
2. 送信したサイトマップのステータスを確認
3. 「成功」ステータスであることを確認

### インデックス状況

1. 「インデックス」→「カバレッジ」をクリック
2. インデックスされたページ数を確認
3. エラーがないか確認

### 検索パフォーマンス

1. 「検索結果」→「パフォーマンス」をクリック
2. 表示回数、クリック数、CTR、掲載順位を確認
3. データが表示されるまで数日かかる場合があります

## 🚨 トラブルシューティング

### サイトマップが見つからない

**原因**: サイトマップが正しく生成されていない

**解決策**:
1. `https://takahiro-motoyama.vercel.app/sitemap.xml` にアクセス
2. サイトマップが表示されるか確認
3. 表示されない場合、ビルドエラーを確認

### インデックスされない

**原因**: ページの品質が低い、またはnoindexタグがある

**解決策**:
1. ページの品質を確認
2. メタタグにnoindexがないか確認
3. 「URL検査」でステータスを確認

### クロールエラー

**原因**: サーバーがダウン、またはページの読み込みが遅い

**解決策**:
1. サーバーの状態を確認（Vercelのステータス）
2. ページの読み込み速度を確認
3. robots.txtを確認
