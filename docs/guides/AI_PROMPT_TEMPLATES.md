# AI活用プロンプトテンプレート集

**作成日**: 2026-01-23
**担当**: 開発チーム
**対象**: Issue #85 - AIを活用した最速収益化

---

## 📋 概要

AI活用による効率化を最大化するための、ChatGPT (GPT-4) で使用するプロンプトテンプレート集です。コンテンツ制作、リサーチ、コード生成などの主要なタスクカテゴリ別に整理しています。

---

## 🎯 プロンプトの基本原則

### 1. 明確な指示（Specific）
- 何を、どのように、いつまでにするのかを明確にする
- 具体的な例やフォーマットを指定する
- 期待される出力のスタイルを指定する

### 2. 適切な役割（Role）
- AIに役割を与え、その視点から応答させる
- 例: 「あなたはエンジニアリングの専門家です」「あなたはマーケティングの専門家です」

### 3. コンテキストの提供（Context）
- ターゲット読者、目的、背景情報を提供する
- 関連する資料や参考情報を提示する
- 使用するツールや技術スタックを明示する

### 4. 形式の指定（Format）
- 出力形式（Markdown、JSON、リストなど）を指定する
- 文字数、構成、スタイルを指定する
- 必須な要素とオプション要素を明確にする

### 5. 繰り返しの余地（Iteration）
- 一度ですべてを出すのではなく、段階的にリファインする
- フィードバックを元に修正を指示する
- 最適な結果が得られるまで繰り返す

### ブログ記事のアウトライン作成

#### テンプレート
```
あなたは技術ブログの記事構成専門家です。

【背景】
- タイトル: 「AI活用による効率化で副業月10万を達成した私のスクリプト」
- ターゲット読者: 25〜40歳のエンジニア、フリーランサー
- 目的: 自分の経験を元に、読者が実践できる具体的なステップを提供する

【目的】
以下の構成で、ブログ記事の詳細なアウトラインを作成してください。
- 各セクションの目標、見出し、本文の構成要素を具体的に示してください。
- 読者がスムーズに読めるように、論理的な流れを作ってください。

【期待される構成】
1. 導入（Hook）
   - 読者の注意を引く問いかけ
   - 記事全体のテーマの提示

2. 背景（Why）
   - なぜこのテーマを選んだのか
   - 読者が直面している可能性のある課題
   - 自身の成功体験（月10万）の簡潔な紹介

3. 成功要因（What）
   - 効率化に貢献した3〜5つの要因
   - AI活用の具体的な方法
   - 人間の介入ポイント

4. 実践ステップ（How）
   - 読者が今週からできる具体的なアクション
   - ステップバイステップの説明
   - 各ステップの期待される時間と成果

5. ツールとリソース（Tools）
   - 推奨されるAIツール（ChatGPT, Claude, Midjourneyなど）
   - 無料/無料プラン
   - 使用のヒント

6. 結果と次のステップ（Next）
   - 期待される成果
   - 継続的な改善のヒント
   - 次のトピックへの誘導

【出力形式】
- Markdown形式
- 各セクションを「## セクション名」で見出しにする
- 各サブセクションを「### サブセクション名」で見出しにする
- 本文の構成要素を「-」で箇条書きにする

【トーン】
- 実践的であり、具体性を重視する
- 読者をリスペクトし、専門家としての立場を崩さない
- 前向きであり、行動を促す
```

```
【出力形式】
- Markdown形式
- 完全な記事のドラフト（導入から結論まで）
- 画像挿入箇所の指示を含む

【トーン】
- 専門的であり、かつ親しみやすく
```

```
   - タスクを更新
   - 更新可能なフィールド: status, priority
   - バリデーション: 更新内容の確認

5. DELETE /api/tasks/[id]
   - タスクを削除
   - タスクID: string

【出力形式】
- TypeScriptコード
- App Routerのroute.tsファイル
- Prismaクライアントを使用
- エラーハンドリングを含める

【トーン】
- 技術的であり、正確であること
- セキュリティを考慮すること
- APIのベストプラクティスに従うこと
```

## 🎨 プロンプトの最適化ヒント

### 複雑なタスクを分割する
- 1つのプロンプトで複数のタスクを依頼しない
- タスクごとに専用のプロンプトを作成する
- 出力を次のタスクの入力として活用する

### 例示を豊富にする
- 良い例と悪い例を提示する
- 具体的な出力イメージを伝える
- 範囲の境界を明確にする

### フィードバックループを回す
- 最初の出力を確認
- 不十分な点を特定
- 改善点を明確にして再プロンプト

### 温度調整（Temperature）の活用
- 創造的なタスク: 高い温度（0.8〜1.0）
- 論理的なタスク: 中程度の温度（0.5〜0.7）
- コード生成: 中程度の温度（0.5〜0.7）

### コンテキストの維持
- チャット履歴を活用する
- 一貫性のあるスタイルを保つ
- 関連する情報を繰り返し参照する
