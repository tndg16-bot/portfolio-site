## 🎨 視覚的アイデンティティ（Visual Identity）

### ロゴデザイン

#### 概念
- **メインコンセプト**: 「自分のやり方を、自分のルールで」
- **サブコンセプト**: 「判断軸を見つけたら、決断を早めに」
- **視覚的イメージ**: 自己決定、自信、成長、調和

#### ロゴタイプ
- **タイプ**: テキストロゴ + アイコン
- **フォント**: Inter (または日本語対応フォント: Noto Sans JP)
- **フォントウェイト**: Bold (700)
- **ロゴマーク**: チェックマーク（自分のやり方を象徴）
- **サイズ**: 
  - フルサイズ: 高さ48px / 幅192px（ブランド名）
  - アイコンのみ: 48x48px (SNSアバター、ファビコン)
  - ワードマーク: 24x24px (ブラウザタブ)

#### ロゴの色
| 要素 | 色 | カラーコード | 透明度 |
|------|------|----------|---------|
| メインテキスト | White (#FFFFFF) | | - |
| アイコン | Teal (#14B8A6) | #14B8A6 | 100% |
| アイコン（グレースケール） | Teal Light (#2DD4BF) | #2DD4BF | 80% |
| 背景（必要な場合） | Transparent | - | 0% |

#### ロガイドライン
- **クリアランス**: ロゴの周りに十分な空白（1.5倍のロゴ高さ）
- **最小サイズ**: デジタルで24px高さ、印刷で1.5cm高さ
- **背景色**: 濃い背景（#111111以上）でロゴを使用
- **禁止事項**: ロゴの変形、回転、ぼかし、追加のグラデーション

## 📝 タイポグラフィ（Typography）

### フォントファミリー

| 要素 | フォント | 用途 |
|------|--------|------|
| **見出し** | Inter (または Noto Sans JP) | H1-H6 |
| **本文** | Inter (または Noto Sans JP) | 段落、リスト、引用 |
| **コード** | JetBrains Mono | インラインコード、コードブロック |
| **キャプション** | Inter (または Noto Sans JP) | キャプション、注釈 |

### フォントサイズ

| 要素 | サイズ | 行の高さ | 太さ |
|------|--------|----------|--------|
| **H1** | 32px | 1.2 | Bold (700) |
| **H2** | 28px | 1.3 | Bold (700) |
| **H3** | 24px | 1.4 | SemiBold (600) |
| **H4** | 20px | 1.5 | SemiBold (600) |
| **H5** | 18px | 1.5 | Medium (500) |
| **H6** | 16px | 1.5 | Medium (500) |
| **本文** | 17px | 1.9 | Regular (400) |
| **小文字** | 14px | 1.5 | Regular (400) |
| **キャプション** | 13px | 1.5 | Regular (400) |
| **コード** | 14px | 1.5 | Regular (400) |

### タイポグラフィの原則

#### 日本語の読みやすさ最適化
1. **行間**: 本文は1.9（行の高さ / フォントサイズ）
2. **文字幅**: 本文は最大65ch（文字数）まで
3. **段落間**: 2em（マージン）の間隔
4. **行の長さ**: 40〜60文字（1文あたり）

#### 見出しの階層化
1. **H1**: ページタイトル（1ページに1回）
2. **H2**: メインセクション（各セクションに1回）
3. **H3**: サブセクション（必要に応じて）
4. **H4-H6**: 詳細なセクション（必要に応じて）
5. **太さと色**: 明確な違いを持たせる

#### 強調の方法
1. **太字**: 重要なキーワードやフレーズ
2. **色**: アクセントカラー（Teal, Emerald, Amber）
3. **サイズ**: 重要度に応じてサイズを調整
4. **位置**: 中央揃え（見出し）と左揃え（本文）

## 📐 アニメーション

### Framer Motion の使用

#### トランジション
- **フェードイン**: opacity: 0 → 1
- **フェードアウト**: opacity: 1 → 0
- **スライドアップ**: y: 20px → 0
- **スライドダウン**: y: -20px → 0
- **スケール**: scale: 0.9 → 1
- **ローテーション**: rotate: -5deg → 0

#### アニメーションの原則
1. **簡潔さ**: 必要最小限のアニメーション
2. **スムーズさ**: デュレーションは300-500ms
3. **一貫性**: すべてのアニメーションで同じイージングを使用
4. **パフォーマンス**: パフォーマンスへの配慮（GPUアクセラレーション）

#### 使用例
```tsx
// フェードインアニメーション
<motion.div
  initial={{ opacity: 0, y: 20 }}
  animate={{ opacity: 1, y: 0 }}
  transition={{ duration: 0.5, ease: "easeOut" }}
>
  コンテンツ
</motion.div>

// ホバーアフェクト
<motion.div
  whileHover={{ scale: 1.02 }}
  transition={{ duration: 0.2 }}
>
  コンテンツ
</motion.div>
```

## 📝 ブランドガイドライン

### 色彩（Tone & Manner）

#### 許されるトーン
- **丁寧**: 読者を尊重し、親切に対応する
- **専門的**: 知見を専門家として提供する
- **前向き**: 機会的で、成長を促す

#### 避けるべきトーン
- **傲慢**: 自分を過剰に持ち上げる
- **説教的**: 「〜すべき」「〜してはいけない」と強制する
- **不明確**: 複雑な表現でわかりにくくする

### 言葉遣い（Word Choice）

#### 許される表現
- 「〜できますか？」→ 可能性を提示
- 「〜という方法があります」→ 選択肢を提供
- 「〜かもしれません」→ 可能性を示唆

#### 避けるべき表現
- 「〜しなければならない」→ 強制的な表現
- 「〜が正解です」→ 唯一解の押し付け
- 「〜してはいけません」→ 禁止事項の強調

## 🎯 ブランドメッセージ

### 主要なメッセージ

1. **「自分のやり方を、自分のルールで」**
   - キャッチコピーとして使用
   - ヘッダーのナビゲーションに表示

2. **「答えは外にあるのではなく、あなたの中にある」**
   - 自己決定を促すコアメッセージ
   - ヒーローセクションに表示

3. **「判断軸を見つけたら、決断を早めに」**
   - 行動を促すメッセージ
   - CTA（コール・トゥ・アクション）で使用

4. **「迷っている時間は、探索の時間だ」**
   - 不確実性をポジティブに捉えるマインドセット
   - ブログやメールで共有

5. **「長期的な関係を構築します」**
   - 信頼関係の構築を重視するビジネスメッセージ
   - 紹介・リピートを獲得する戦略で使用
