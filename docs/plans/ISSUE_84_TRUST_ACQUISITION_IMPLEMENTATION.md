# Issue #84: 信頼獲得型の案件獲得戦略 - 実装計画

**作成日**: 2026-01-23
**Issue番号**: #84
**優先度**: 高
**担当**: 開発チーム

---

## 📋 概要

一時的なセールスではなく、長期的な信頼関係を構築し、紹介・リピートを獲得する営業手法を確立します。営業代行マイナビの知見を活かし、感情と論理に訴えるアプローチを探求します。

---

## 🎯 目的

1. **信頼構築プロセスの確立**: 長期的な信頼関係を築くための明確なプロセス
2. **感情と論理のバランス**: 顧客の理性と感情の両方にアプローチ
3. **フォローアップ戦略の策定**: 自然なフォローのタイミングと方法
4. **顧客体験の最適化**: 全体的な顧客体験を向上
5. **成功事例の蓄積**: 信頼を証明する事例データベースの構築

---

## 🔄 実装フェーズ

### フェーズ1: 信頼構築の設計（第1週）

#### タスク1.1: 信頼の定義と重要性の明確化
- [ ] 信頼の定義を言語化
  - 「期待を満たすこと」
  - 「約束を守ること」
  - 「誠実であること」
- [ ] 信頼の重要性を説明
  - 長期的な関係の価値
  - 紹介・リピートの重要性
  - 価格よりも関係性の重視

#### タスク1.2: 信頼構築のプロセスを設計
- [ ] 初回接触から契約までのプロセスを設計
  1. 認知（コンテンツマーケティング）
  2. 興味（無料相談のオファー）
  3. 信頼構築（ヒアリングや体験提供）
  4. 提案（カスタマイズされた提案書の作成）
  5. 契約
  6. フォローアップ（長期的な関係の維持）
- [ ] 各フェーズの目的と期待される成果を明確化

#### タスク1.3: 信頼を壊す要因を特定
- [ ] 信頼を損なう行動をリストアップ
  - 過度なセールス
  - 不実な約束
  - 価格の不透明性
  - 不十分なフォローアップ
  - コミュニケーションの欠如
- [ ] 信頼を壊す要因の回避策を策定

#### タスク1.4: 信頼回復プロセスを策定
- [ ] 信頼が損なわれた場合の対処プロセスを設計
  - 早期の発見と謝罪
  - 具体的な改善策の提示
  - 補償の提供
  - 関係修復のためのフォローアップ

**成果物**:
- 信頼構築プロセスの設計書
- 信頼を壊す要因のリスト
- 信頼回復プロセスの設計書

---

### フェーズ2: 感情と論理のバランス（第2週）

#### タスク2.1: 感情的なアプローチの効果を理解
- [ ] 感情を動かすための手法を調査
  - 共感を生む物語（事例）
  - 親近感のある表現
  - 顧客のペインポイントへの共感
  - 顧客の成功への共感
- [ ] 感情を動かすための言語の選定
  - 「あなたの〜」というパーソナルな表現
  - 「私も〜」という共感表現
  - 「〜でしょう」という柔らかい表現

#### タスク2.2: 論理的なアプローチの効果を理解
- [ ] 論理を説得するための手法を調査
  - データや統計の活用
  - 成功事例や実績の提示
  - 明確なメリットとデメリットの提示
  - 比較（他社との比較）
- [ ] 論理を説得するための構成の選定
  - 結論（前提→結論）
  - ピラミッド構造（最重要→重要→詳細）
  - 反論への先回り（Q&A形式）

#### タスク2.3: バランスの最適なポイントを特定
- [ ] 感情と論理のバランスが最適なシナリオを特定
  - 初回接触：感情7割・論理3割
  - 説明フェーズ：感情5割・論理5割
  - 提案フェーズ：感情3割・論理7割
  - 成約フェーズ：感情4割・論理6割
- [ ] 顧客タイプ別のバランス調整
  - 若年層：感情6割・論理4割
  - 中堅層：感情4割・論理6割
  - 経営者：感情3割・論理7割

#### タスク2.4: シナリオ別の対応方針を作成
- [ ] 各シナリオのトークン（キーフレーズ）を作成
  - 「その気持ち、すごく分かります」
  - 「確かに、そうですね」
  - 「もしそうなら、〜という方法もあります」
  - 「では、具体的に〜というアクションをとりましょうか」
- [ ] 難談のロールプレイ練習
  - 顧客役：懸念を持っている
  - 営業担当役：信頼性のある専門家

**成果物**:
- 感情と論理のバランスに関する分析レポート
- シナリオ別の対応方針マニュアル
- トークン集

### フェーズ3: フォローアップ戦略（第3週）

#### タスク3.1: 顧客のライフサイクルをマッピング
- [ ] 顧客のライフサイクルの各段階を定義
  1. 認知（コンテンツ、イベント）
  2. 興味（問い合わせ、相談）
  3. 検討（提案、比較検討）
  4. 成約（契約、導入）
  5. 運用（サポート、フォローアップ）
  6. 拡大（アップセル、紹介）
- [ ] 各段階での期待される行動を定義

#### タスク3.2: 価値提供のタイミングを特定
- [ ] フォローアップのタイミングを設計
  - 成約後1週間以内：オンボーディング完了確認
  - 成約後1ヶ月：成果確認と追加サポート
  - 成約後3ヶ月：中間レビューと改善提案
  - 成約後6ヶ月：アップセルのオファー
- [ ] 価値提供の方法を設計
  - 定期的なチェックイン（メール、電話）
  - 新機能の案内（ニュースレター）
  - 成功事例の共有（事例ブログ）

#### タスク3.3: 自然なフォローアップ戦略を策定
- [ ] 強引なフォローのリスクを管理
  - 「いつご連絡すればよいですか」という許可を得る
  - コミュニケーションの頻度に注意（週2〜3回が適切）
  - セールの開封率を意識（魅力的な件名、明確な目的）
- [ ] 価値ベースのフォローアップを設計
  - 「売る」のではなく「支援する」というスタンス
  - 顧客の成功を中心にしたコンテンツ提供
  - 新規価値の提案（無償のヒントやアドバイス）

#### タスク3.4: 長期的な関係の構築戦略
- [ ] パートナーシップの設計
  - 単発の契約ではなく、パートナーシップとしての提案
  - 年次契約のオファー（価格優遇）
  - 顧客のビジネス成長を支援するスタンス
- [ ] コミュニティ形成の戦略
  - 顧客同士の交流イベントの開催
  - マスターマインドクラスやワークショップの提供
  - 顧客の成功事例を広める協力

**成果物**:
- 顧客ライフサイクルの設計書
- フォローアップ戦略の設計書
- パートナーシップの提案テンプレート

---

### フェーズ4: 顧客体験の最適化（第4週）

#### タスク4.1: 顧客体験の現状を分析
- [ ] 既存の顧客体験を評価
  - コンタクトフォームの使いやすさ
  - コンテンツの分かりやすさ
  - サポート対応のスピードと質
  - 成約後のオンボーディング体験
- [ ] 顧客フィードバックの収集方法を策定
  - 顧客アンケート（Typeform）
  - 定期的なNPS（ネットプロモータースコア）調査
  - チャットサポートの質の評価
  - メールでのフィードバック収集

#### タスク4.2: ペインポイントを特定
- [ ] 顧客体験の問題点をリストアップ
  - コンテンツが専門用語すぎる
  - 契約プロセスが複雑すぎる
  - サポート対応が遅い
  - オンボーディングが不十分
- [ ] 問題点の優先順位を設定
  - 顧客満足度に最も影響を与える点から優先
  - 実装の難易度と効果のバランスを考慮

#### タスク4.3: ペインを解消する方法を策定
- [ ] 各問題点に対する解決策を立案
  - 専門用語の平易な表現への言い換え
  - 契約プロセスの簡素化
  - サポート体制の強化
  - オンボーディング資料の充実
- [ ] 改善の優先順位と実装スケジュールを策定

#### タスク4.4: 顧客体験の継続的な改善プロセスを策定
- [ ] 顧客の声を組織的に収集する仕組みを設計
  - 毎月のフィードバック収集
  - 四半期ごとの調査
  - 顧客サミットの開催（年1回）
- [ ] 改善のPDCAサイクルを設計
  - Plan: 改善策の立案
  - Do: 実装とテスト
  - Check: 効果の測定と評価
  - Act: 標準化と拡張

**成果物**:
- 顧客体験の現状分析レポート
- ペインポイントのリストと優先順位
- 顧客体験改善の設計書
- PDCAサイクルの設計書

## 📊 成功指標（KPIs）

### 顧客満足度
| 指標 | 目標 | 測定方法 | 期限 |
|------|------|----------|------|
| NPSスコア | 60以上 | 四半期ごとの調査 | 四半期 |
| 顧客満足度 | 4.5/5以上 | 定期的なアンケート | 月次 |
| リピート購入率 | 40%以上 | 購入データの分析 | 月次 |

### 信頼指標
| 指標 | 目標 | 測定方法 | 期限 |
|------|------|----------|------|
| 紹介獲得数 | 5件/月 | 紹介元の記録 | 月次 |
| 紹介品質スコア | 4.0以上 | 紹介された顧客の満足度 | 月次 |
| 顧客生涯価値（LTV） | ¥300,000以上 | 平均契約期間 × 月額 | 月次 |

### フォローアップ指標
| 指標 | 目標 | 測定方法 | 期限 |
|------|------|----------|------|
| フォローアップ実施率 | 90%以上 | 予定されたフォローアップの実施率 | 月次 |
| セール開封率 | 40%以上 | メールツールの統計 | 月次 |
| コンテンツ閲覧率 | 60%以上 | コンテンツの閲覧数 / 送信数 | 月次 |

## ⚠️ リスク管理

### 主要リスク
| リスク | 影響 | 緩和策 | 優先度 |
|--------|------|----------|--------|
| 信頼構築に時間を要する | 開発期間の延長 | 短期的な成果を重視しつつ、長期的関係の価値を教育 | 高 |
| 感情と論理のバランスが難しい | 顧客満足度の低下 | シナリオ別のトークンとロールプレイ練習 | 高 |
| フォローアップの強引さが問題になる | 顧客離れの原因 | 価値提供に焦点を当て、強引さを回避 | 中 |
| 顧客体験の改善にコストがかかる | 利益率の低下 | 効果の高い改善から優先的に実施 | 中 |
