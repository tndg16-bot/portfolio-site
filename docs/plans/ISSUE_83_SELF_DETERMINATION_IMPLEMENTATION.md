# Issue #83: 自己決定に基づく独自の商品設計 - 実装計画

**作成日**: 2026-01-23
**Issue番号**: #83
**優先度**: 高
**担当**: 開発チーム

---

## 📋 概要

価格競争から脱却し、高単価で唯一無二のサービスを設計します。自己決定（自己決定プロセス）に基づいた価値提供を中心とした製品・サービスの設計手法を確立します。

---

## 🎯 目的

1. **価格競争からの脱却**: 「自分のやり方」という独自の価値提供で、価格競争に陥らない
2. **高単価化**: 自分の価値観に共鳴する層に対し、高い価格でも購入してもらえる価値を提供
3. **唯一無二性**: 他者と比較できない独自のポジショニングを確立
4. **顧客ロイヤルティの向上**: 長期的な関係を築くための製品体験を提供

---

## 🔄 実装フェーズ

### フェーズ1: 基礎研究（第1週）

#### タスク1.1: 既存の価格競争製品を調査
- [ ] Basecamp, Notion, Figma, Miroなどの価格戦略を詳細に分析
- [ ] 成功している製品の価格構造を分解
  - フリーミアム期間と有料機能のバランス
  - 年次契約と月額の価格設定
  - エンタープライズ向けのオプション
- [ ] ターゲット層ごとの価格感受性の調査
  - 若年層: 価格感度が低いが、機能重視
  - ビジネスオーナー: ROI重視、高価格でも許容
  - 個人: シンプルさ重視、中価格帯

#### タスク1.2: 顧客の価値観を分析
- [ ] 「自分のやり方」で重視される要素を特定
  - カスタマイズ性: 自分のワークフローを完全に制御できること
  - 達成感: 自分の設定で目標を達成したこと
  - 学習・成長: 自分のスキルを向上できる環境
- [ ] 価値観に対応する製品機能のリストアップ
- [ ] 価値観を測定する指標（NPS、ユーザー満足度）の定義

#### タスク1.3: 成功する価値観を特定
- [ ] 既存の成功製品が提供している「自分のやり方」を分析
  - Basecamp: プロジェクトの独自なオーガナイズ
  - Notion: データベースの自由な構造
  - Figma: ワークフローの完全なコントロール
- [ ] 価値観の共通点と差異点の比較
- [ ] 自分の製品で提供できる独自の価値観を特定

#### タスク1.4: 市場のギャップを特定
- [ ] 現在の製品が満たしていないニッチを特定
  - 「自分のやり方」を尊重しつつ、よりよい体験を提供できる製品
  - 既存の製品が見落としているターゲット層
  - 技術的に解決可能な痛み
- [ ] ギャップのビジネス価値を評価

**成果物**:
- 競合製品の価格戦略レポート
- 顧客価値観の分析レポート
- 市場ギャップの特定レポート

### フェーズ3: 価格戦略（第3週）

#### タスク3.1: コスト構造を分析
- [ ] 製品・サービスのコストを分解
  - 開発コスト: 工数、期間
  - 運営コスト: サーバー、SaaSツール、メンテナンス
  - マーケティングコスト: 広告、コンテンツ制作
  - 顧客サポートコスト: 人件費
- [ ] 月間の総コストの計算
- [ ] 利益マージンの算出

#### タスク3.2: 価格モデルを設計
- [ ] プライシングモデルの選定
  - Good-Better-Best (GBB) の3段階価格
    - Good: ¥10,000/月（基本機能）
    - Better: ¥20,000/月（標準機能）
    - Best: ¥30,000/月（高度な機能）
  - フリーミアム期間: 2週間〜1ヶ月
  - 年次契約: 10〜20%のディスカウント
- [ ] エンタープライズ向けのプラン
  - ¥50,000/月〜¥200,000/月（チームサイズによる）
  - オプション機能: メンバー管理、分析機能、APIアクセス

#### タスク3.3: 競合製品との価格比較
- [ ] 競合製品の価格表の作成
- [ ] 自分の製品の価値と価格の整合性の確認
- [ ] 「高価格でも納得してもらえる」価値の言語化
- [ ] 価格設定のテスト（仮想の顧客インタビュー）

#### タスク3.4: 適正な価格帯を設定
- [ ] ターゲット層ごとの価格帯の設定
  - 若年層: ¥8,000/月〜¥15,000/月
  - ビジネスオーナー: ¥30,000/月〜¥80,000/月
  - 個人: ¥15,000/月〜¥25,000/月
- [ ] 価格の心理的な境界（¥10,000、¥20,000、¥30,000）を考慮
- [ ] プロモーション価格の策定
  - 初回契約の50%OFF（初月）
  - 年次契約の15%OFF

**成果物**:
- コスト構造の分析レポート
- 価格モデルの設計書
- 価格比較表
- 価格設定の最終案

### フェーズ4: ブランド戦略（第4週）

  - 「自分のルールで」を可能にするが、道しるべという姿勢
- [ ] ブランドのトーン＆マナーの策定
  - 丁寧、親切、専門的、前向き
  - 「〜すべき」という指示より、「〜できますか？」という問いかけ
- [ ] ブランドのストーリーの作成
  - 誰り手自身の体験を交えたストーリー
  - 「自分のやり方」で成功した事例の共有

#### タスク4.2: ビジュアルアイデンティティを策定
- [ ] カラーパレットの策定

  - セカンダリー: Emerald (#10B981) - 成功、繁栄
  - アクセント: Amber (#F59E0B) - エネルギー、創造性
  - ニュートラル: Zinc (#71717A) - 洗練さ、専門性
- [ ] フォントの選定
  - 見出し: 17px、line-height 1.9、font-weight 600〜700
  - 本文: 17px、line-height 1.9
  - 読みやすさを重視したフォント（日本語対応）
- [ ] アイコンの選定
  - Lucide React を使用
  - シンプルで分かりやすいアイコン
  - 一貫したサイズと色使い

#### タスク4.3: 顧客体験のデザイン
- [ ] ユーザー体験（UX）の原則の策定
  - シンプルで直感的なインターフェース
  - 「自分のやり方」をカスタマイズできる柔軟性
  - 慣れやすさ（学習コストの低さ）
- [ ] オンボーディングの設計
  - チュートリアルの作成
  - インタラクティブな学習体験
  - 成功体験の設計（達成時のフィードバック）
- [ ] プログレスバーの設計
  - タスク完了、ゴール達成の可視化
  - 進捗に応じた報酬や称賛

#### タスク4.4: ブランドストーリーの作成
- [ ] 誰り手自身のストーリー
  - 「なぜこの製品を作ったのか」

  - 「価格競争ではなく、価値観のマッチングで勝つ」
