# 自己決定プロセスの詳細な実装計画

**作成日**: 2026-01-23
**担当**: 開発チーム
**対象**: Issue #83 - 自己決定に基づく独自の商品設計（実装フェーズ）

---

## 📋 概要

自己決定プロセスを製品・サービスに実装し、ユーザーが「自分のやり方を、自分のルールで」決定できるように支援します。

---

## 🎯 実装の目的

1. **自己決定プロセスの可視化**: 6つのステップをUIで実装
2. **問い場合（スクリプト）の提供**: 迷った時に使える問いリストの実装
3. **進捗の可視化**: 各ステップの完了状況をプログレスバーで表示
4. **ジャーナル機能**: 自己決定プロセスの記録と振り返り機能

## 🎨 問い場合（スクリプト）の実装

### 問い場合の種類

| カテゴリー | 問い例 | 用途 |
|-----------|--------|------|
| 状況を明確化するための問い | 「今の状況をどう理解していますか？」 | 現状の把握 |
| 目標を設定するための問い | 「どんなゴールを目指しますか？」 | 目標の明確化 |
| 選択肢を評価するための問い | 「どのような選択肢がありますか？」 | 選択肢の提示 |
| 価値観を確認するための問い | 「自分の価値観は何ですか？」 | 価値観の確認 |
| 直感的な感覚を確認するための問い | 「自分の直感は何を言っていますか？」 | 直感的感覚の確認 |
| 決定を促すための問い | 「どの選択肢を選びますか？」 | 決定の促し |
| 振り返しの学習を促すための問い | 「期待通りにいきましたか？」 | 振り返しの学習 |

### 問い場合の実装

#### 問い場合の構成

```typescript
interface Script {
  id: string;
  category: ScriptCategory;
  question: string;
  followUpQuestions?: string[];
  expectedAnswerType?: 'text' | 'choice' | 'rating';
}

interface ScriptCategory {
  id: string;
  name: string;
  description: string;
  icon: string;
}

// Example script
{
  id: "script-1",
  category: "situation-clarity",
  question: "今の状況をどう理解していますか？",
  followUpQuestions: [
    "何が起きているのか、客観的に言えますか？",
    "何を決定する必要がありますか？",
    "どんな情報が不足していますか？"
  ],
  expectedAnswerType: "text"
}
```

#### 問い場合のUI実装

1. **問いの表示**
   - 大きなフォントサイズ（24px）
   - 明確なトーン（丁寧）
   - アイコンの使用（問いカテゴリーのアイコン）

2. **入力フィールドの提供**
   - テキストエリア：自由な回答の入力
   - チョイスセレクト：予め定義された選択肢
   - レーティング：5段階の評価（1〜5）

3. **フォローアップ質問の表示**
   - 現在の問いに応じて、フォローアップ質問を表示
   - スライドダウンまたはタブ形式

4. **回答の保存**
   - ユーザーの回答をローカルまたはクラウドに保存
   - ジャーナル機能との連携

## 🎨 ジャーナル機能の実装

### ジャーナルの目的

自己決定プロセスを記録し、振り返りと学習を可能にします。

### ジャーナルの機能要件

| 機能 | 説明 | 優先度 |
|------|------|----------|
| 日付と時間の記録 | いつ、どのような決定をしたかを記録 | 高 |
| 決定内容の記録 | 何を決定したか、どのような選択肢を選んだか | 高 |
| 理由の記録 | なぜその決定をしたか、どのような価値観に基づいたか | 高 |
| 結果の記録 | 決定の結果、期待通りに行ったか | 中 |
| 学びの記録 | 何を学んだか、次回はどう改善できるか | 中 |
| タグ付け | ジャーナルエントリの分類（例：#自己決定, #価格決定） | 低 |
| 検索機能 | 過去のジャーナルエントリの検索 | 低 |

### ジャーナルのUI実装

1. **ジャーナル一覧ページ**
   - 最新のジャーナルエントリの表示
   - カレンダービュー（月ごとの表示）
   - タグによるフィルタリング
   - 検索機能

2. **ジャーナル詳細ページ**
   - 日付、時間、決定内容の表示
   - 理由、結果、学びの表示
   - 関連する問い場合（スクリプト）のリンク
   - タグの編集

3. **ジャーナル作成・編集ページ**
   - フォームベースの入力
   - 自動保存機能
   - リッチテキストエディタ（Markdownサポート）
