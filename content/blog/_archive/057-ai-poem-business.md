## はじめに

AIは論理的で構成された文章を得意としますが、情緒的で共感を呼ぶ表現は人間の領域です。ビジネス文章とポエム（情緒的表現）の使い分けを理解し、AIと人間の強みを活かした文章作成を実現しましょう。

## AIと人間の強みの違い

### AIが得意な領域

- **論理構造**：ピラミッド構造、因果関係
- **情報統合**：多様な情報の整理
- **一貫性**：トーンやスタイルの統一
- **速度**：ドラフトの迅速な作成

### 人間が得意な領域

- **情緒的共感**：心を動かす言葉
- **文脈理解**：文化的・状況的ニュアンス
- **独自の視点**：個性的な表現
- **直感**：論理では説明できない選択

## ビジネス文章：AI活用の領域

### 適したシーン

- レポートや企画書
- 説明的なブログ記事
- メールや報告
- プレゼン資料の構成

### AI活用のワークフロー

**Step 1：構成案の作成**
```
「以下のテーマについて、ビジネス文章の構成案を作成してください：

【テーマ】○○
【目的】△△
【読み手】□□

【構成案】
1. エグゼクティブサマリー
2. 背景と問題提起
3. 解決策の提示
4. 実施計画
5. まとめ」
```

**Step 2：ドラフト作成**
各セクションのドラフトをAIに作成してもらいます。

**Step 3：人間による調整**
- 会社のトーンに合わせた修正
- 特定のデータや事例の挿入
- 論理の飛躍がないか確認

## 情緒的表現：人間の領域

### 適したシーン

- 感謝の手紙
- 励ましのメッセージ
- ビジョンの共有
- ストーリーテリング

### 人間が創るべき要素

**情緒的な導入：**
```
「あの日のこと、覚えていますか。
雨が降る中、私たちが初めて会った日のこと。」
```

**個人的なエピソード：**
```
「私自身、3年前に同じ悩みを抱えていました。
深夜のオフィスで、一人モニターを見つめながら...」
```

**共感を呼ぶ問い：**
```
「あなたも、こんな経験はありませんか？」
```

## ハイブリッド型文章の作成

### 構造と情緒の組み合わせ

**フレームワーク：**
- AIが論理構造を設計
- 人間が情緒的な要素を挿入
- AIが全体の調整
- 人間が最終的なトーン確認

### 実践例

**ビジネスメールに情緒を加える：**
```
【AI作成の基本構造】
件名：プロジェクト完了のご報告

山田様、

プロジェクトが完了しました。
結果は予定通り納品されました。
...

【人間が加える情緒】
件名：苦楽を共にした○○プロジェクト、無事完了しました

山田様、

3ヶ月間、本当にお疲れ様でした。
あの厳しい状況から、一緒に這い上がってきた仲間として、
今の達成感はひとしおです。
...
```

## 具体的手法

### AIに依頼すべきこと

- 情報の整理と構造化
- 論理的な流れの設計
- データに基づく説明
- 客観的な分析

### 人間が加えるべきこと

- 個人的な経験やエピソード
- 感謝や共感の表現
- 文化的な配慮
- 独特の比喩や表現

## まとめ

AIと人間の強みを理解し、適切に使い分けることで、論理的でありながら情緒的な文章が作成できます。状況に応じて最適なアプローチを選択しましょう。

**今週からの実践：**
1. 次の文章を書く時、どこまでAIに任せるか決める
2. AIに構造とドラフトを依頼
3. 人間が情緒的な要素を加える
4. バランスを確認して完成

AIの論理と人間の情緒を組み合わせ、効果的な文章を作りましょう。
