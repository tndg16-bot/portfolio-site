## はじめに

デスクの上に書類が山積みになっていませんか？「あとで整理しよう」と思いながら、どんどん増えていく書類。書類の「一読一処」（一度手にしたらその場で処理）の原則を徹底することで、机の上の混沌を解消し、生産性を高めることができます。

## 一読一処の原則

### 基本ルール

**「手にした書類は、即座に以下のいずれかにする」**
1. 処理する（その場で）
2. 処分する（ゴミ箱へ）
3. 保管する（ファイルへ）
4. 次のアクション（ToDoへ）

**禁止事項：**
- 「あとで」スタックへの積み上げ
- デスク上の放置
- 「後で見る」という先延ばし

### なぜ有効か

**心理学的効果：**
- 未処理の書類は脳に負担
- 「ゼイガルニク効果」で気にかかる
- 一読一処で脳のリソース解放

**実用的効果：**
- 書類の紛失防止
- 検索時間の短縮
- デスク上のスペース確保

## 実践ステップ

### Step 1：処理の分類を決める

書類を受け取った時の判断基準を設定します。

**判断フロー：**
```
書類を受け取る
↓
今すぐ処理できるか？（2分以内）
→ YES：即処理
→ NO：次へ
↓
処分できるか？（不要なもの）
→ YES：即廃棄（シュレッダー）
→ NO：次へ
↓
保管が必要か？
→ YES：ファイルへ
→ NO：ToDoリストへ（次のアクション）
```

### Step 2：即処理の基準

その場で処理する基準を設定します。

**即処理例（2分以内）：**
- サインが必要な書類（既に内容確認済み）
- 承認ボタンのクリック
- 簡単な日程調整
- 既知の情報の確認

**ToDo化例：**
- 読む必要のある文書
- 返答に検討が必要なもの
- 他者との調整が必要なもの
- 時間のかかる作業

### Step 3：保管システムの構築

保管する書類の整理システムを作ります。

**シンプルなファイル構成：**
```
【書類保管】
├── 01_進行中
│   └── 現在取り組んでいる書類
├── 02_参考資料
│   └── 頻繁に参照する書類
├── 03_年度別保管
│   └── 2026年
│       ├── 01_プロジェクトA
│       ├── 02_プロジェクトB
│       └── 03_一般文書
└── 04_要保存書類
    └── 法的・重要書類
```

**ファイルのルール：**
- 命名規則：日付_内容_版（20260115_企画案_v1）
- 1フォルダー50ファイルまで
- 年度末の見直しと整理

### Step 4：物理的な環境整備

デスク周りを整備します。

**必須アイテム：**
- 書類トレイ（入口・出口）
- ファイルボックス
- シュレッダーまたは機密書類ボックス
- ペン、付箋

**デスク上のルール：**
- 処理待ち書類はトレイに（5枚まで）
- 進行中書類は専用フォルダーに
- 完了した書類は即ファイルへ

## 応用：デジタル書類への応用

### メールの一読一処

**メール処理フロー：**
```
メールを開く
↓
即対応可能か？（3分以内）
→ YES：即返信・処理
→ NO：次へ
↓
保存必要か？
→ YES：フォルダへ移動
→ NO：削除
↓
対応必要か？
→ YES：ToDoリストへ
→ NO：アーカイブ
```

**メールの4D：**
- Do（即対応）
- Delegate（委任）
- Defer（後回し→ToDo）
- Delete（削除）

### デジタルファイルの整理

**フォルダ構成：**
- 00_受信トレイ（一時的）
- 01_進行中
- 02_参考資料
- 03_プロジェクト別
- 04_年度別保管
- 99_ゴミ箱（30日で自動削除）

## 注意点と維持

### 定期的な見直し

**週次（15分）：**
- デスク上の書類を確認
- 不要なものを処分
- ファイルの整理

**月次（30分）：**
- ファイルの見直し
- 不要な書類の処分
- システムの改善

### 例外処理

**「とりあえず」への対処：**
- 「とりあえずトレイ」は1つだけ
- 5枚以上になったら即処理
- 週末には必ず空にする

## まとめ

書類の「一読一処」は、デスク上の混沌を解消し、脳のリソースを解放する強力な原則です。一度手にした書類は、即座に処理、処分、保管、またはToDo化し、デスクを常にクリーンに保ちましょう。

**明日から始めるステップ：**
1. 今：デスク上の書類を全て処理
2. 明日：一読一処を徹底
3. 今週：ファイルシステムを構築
4. 継続：週次の見直し

一読一処で、書類の山から解放されましょう。
