## はじめに

プレゼン資料の作成は、内容の構成案を考える段階で最も時間がかかります。何から話し始めて、どう展開し、どう締めくくるか。AIをコンサルタントとして活用することで、この構成案を驚くほど短時間で完成させることができます。今回は、30分でプレゼン構成案を完成させる具体的な手法を解説します。

## 準備：プレゼンの前提条件を明確にする

### 5W1Hの整理

AIに構成案を依頼する前に、以下を明確にしておきます：

1. **Who（聞き手）**：誰に向けたプレゼンか（役職、関心、知識レベル）
2. **What（目的）**：何を達成したいか（承認を得る、理解してもらう、行動してもらう）
3. **Why（背景）**：なぜこのプレゼンが必要か
4. **When（時間）**：発表時間は何分か
5. **Where（場所）**：オンラインか対面か、規模は？
6. **How（方法）**：どんな雰囲気で伝えたいか

これらを整理しておくことで、AIからの提案の精度が劇的に向上します。

### 核心メッセージの1文化

プレゼンの全てを貫く「核心メッセージ」を1文で表現します。例えば：
- 「新市場進出のためには、今四半期に投資を決断する必要がある」
- 「顧客満足度向上には、担当者教育の強化が不可欠である」

この核心メッセージは、構成案作成の指針となります。

## 30分ワークフロー

### Phase 1：ターゲット分析（5分）

AIに聞き手の分析を依頼します。

**プロンプト例：**
```
「○○（聞き手の属性）に向けたプレゼンを作成します。
彼らがこのテーマについて持っているであろう知識レベル、興味・関心、
懸念事項を予測し、それぞれ3つずつ列出してください。
また、この聞き手が最も重視するであろう価値観や判断基準も教えてください。」
```

AIは、聞き手のペルソナに基づいた分析を提供します。この分析を基に、聞き手の心に響く内容を選択していきます。

### Phase 2：構成案の生成（10分）

ターゲット分析を基に、AIに構成案を依頼します。

**プロンプト例：**
```
「以下の条件でプレゼン構成案を作成してください：

【条件】
- 聞き手：△△（Phase 1で分析した結果）
- 目的：○○の承認を得る
- 時間：15分（質疑応答除く）
- 核心メッセージ：□□

【出力形式】
1. 導入（フック）：聞き手の興味を引く導入案3パターン
2. 本論：論理的な展開（各セクションの目的とキーポイント）
3. 結論：核心メッセージの強調とネクストアクション
4. 想定質問：聞かれそうな質問と回答のポイント3つ」
```

AIは、聞き手の特性に合わせた複数の構成案を提案します。中から最も適切と思われるものを選び、または複数の案を組み合わせます。

### Phase 3：各セクションの詳細化（10分）

選んだ構成案の各セクションについて、詳細を詰めていきます。

**プロンプト例：**
```
「以下の構成案について、各セクションの詳細を詰めてください：

【構成案】
（Phase 2で選んだ構成案を貼り付け）

【依頼内容】
1. 各セクションで伝えるべき「1つの核心メッセージ」
2. 説明に使える「具体例」または「データ」
3. 聞き手の疑問に先回りする「反論への対応」
4. 次のセクションへの「繋ぎのフレーズ」
5. 視覚的に表現すべき内容（図表の提案）」
```

### Phase 4：最終調整とストーリー化（5分）

最後に、全体の流れをストーリーとして調整します。

**プロンプト例：**
```
「以下の構成を、ストーリーとして聞き手の感情に訴える形に調整してください：

【現在の構成】
（Phase 3までの内容を貼り付け）

【調整ポイント】
- 導入で「問題提起」または「意外性」を入れる
- 中盤で「緊張感」または「期待感」を高める
- 結論で「解決」と「行動への動機付け」を強調
- 全体を通じて一貫した「比喩」または「フレーム」を使用」
```

## 具体的な構成パターン集

### パターン1：Problem-Solution-Benefit

**構成：**
1. **Problem（問題）**：現状の課題や痛みを提示
2. **Solution（解決策）**：提案する解決策を説明
3. **Benefit（メリット）**：解決策による具体的な効果

**向いているシーン：**
- 新規企画の提案
- 改善案の提示
- 投資の承認を得る

### パターン2：What-So What-Now What

**構成：**
1. **What（事実）**：何が起きているか、データや事実を提示
2. **So What（意味）**：その事実が意味するもの、重要性を解説
3. **Now What（行動）**：今後どうすべきか、具体的なアクション

**向いているシーン：**
- 進捗報告
- 市場分析の共有
- プロジェクトレビュー

### パターン3：Story-Insight-Action

**構成：**
1. **Story（物語）**：具体例やケースストーリーから始める
2. **Insight（洞察）**：ストーリーから導き出される本質的な教訓
3. **Action（行動）**：その洞察をどう活かすか

**向いているシーン：**
- エンゲージメントを高めたい場面
- カルチャー変革やマインドセットの変更
- 説得力より共感を重視する場面

## AI活用のポイントと注意点

### プロンプトの精度を高めるコツ

**文脈を具体的にする：**
「15分のプレゼン」ではなく「15分のエレベーターピッチ風プレゼン」のように、具体的な文脈を添えると精度が上がります。

**制約条件を明確にする：**
「3セクション以内」「各セクション2分以内」「専門用語を避ける」などの制約を明示すると、実用的な提案が得られます。

**複数パターンを求める：**
「3つの構成案を提案してください」と依頼し、選択肢を持つことで、最適な案を選びやすくなります。

### AIの限界を理解する

**業界知識の限界：**
AIは一般的なビジネスフレームワークは知っていますが、業界固有の文脈や社内の独自ルールまでは理解できません。提案された構成は、必ず実際の文脈に当てはめて検証してください。

**文化の違い：**
AIの提案は、主に北米・欧州のビジネス文化に基づいていることが多いです。日本の組織文化や商習慣に合わせた調整が必要な場合があります。

## スライド作成への応用

### AIによるスライド原案作成

構成案が完成したら、次は各スライドの原案をAIに作成してもらいます。

**プロンプト例：**
```
「以下の構成に基づき、各スライドの原案を作成してください：

【スライド形式】
- タイトル：1行で核心を表現
- キービジュアルの提案：図表や画像のアイデア
- 本文：箇条書き3点以内、各30字以内
- スピーカーノート：話す内容のポイント

【構成】
（完成した構成案を貼り付け）」
```

### ビジュアライゼーションのアイデア

AIに視覚的な表現のアイデアも依頼できます。

**プロンプト例：**
```
「プレゼンの各セクションで、最も効果的な視覚的表現を提案してください：
- 図表の種類（グラフ、図、写真、アイコンなど）
- 色使いの意図
- レイアウトのアイデア」
```

## まとめ：AIでプレゼン作成を革新する

AIを活用したプレゼン構成案の作成は、時間短縮だけでなく、多角的な視点からの提案を得られるという利点もあります。ただし、AIの提案は「出発点」であり、最終的な判断と調整は人間が行う必要があります。

**今回のプレゼンで試すステップ：**
1. プレゼン前日：30分のワークフローで構成案を完成させる
2. プレゼン当日：構成案を基にスライドを作成・調整
3. プレゼン後：構成の効果を振り返り、次回のプロンプトに反映

次のプレゼンでは、AIをコンサルタントとして活用し、より説得力のある構成を目指しましょう。
