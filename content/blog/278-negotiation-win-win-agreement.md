## はじめに

「交渉は勝負だ」「譲るのは負けだ」

そう思っていませんか？

でも、本当に効果的な交渉は、**相手を倒すことではありません**。

**お互いにとって最善の合意を作り出すこと**です。

これが「Win-Win」の交渉メンタルモデルです。

## 実例：Win-Winが生んだ奇跡の契約

あるIT企業とクライアントの交渉。当初は予算の問題で対立していました。

従来なら「値下げ対応」か「断る」かの二者択一でした。

でも担当者はWin-Winを追求しました：

**クライアントの本当の利害**：
- 予算内で収める（表面的）
- 社内で成果を証明したい（本質的）

**提案したWin-Win案**：
- フェーズ分けして初期投資を抑える
- 初期成果が出たら追加投資
- 成功事例として社内発表のサポート

**結果**：双方が満足する合意が成立。今では長期的なパートナー関係に発展しています。

## Win-Win交渉の4原則

### 1. 人と問題を分離する

```mermaid
graph TD
    A[攻撃的な態度]
    A --> B[人を攻撃]
    B --> C[対立激化]
    
    D[建設的な態度]
    D --> E[問題に焦点]
    E --> F[解決へ]
```

**「あなたは間違っている」ではなく、「この問題を解決しましょう」**。

### 2. 利害に焦点を当てる

```mermaid
graph TD
    A[立場<br/>"これが欲しい"]
    A --> B[表層的]
    B --> C[対立しやすい]
    
    D[利害<br/>"なぜそれが必要か"]
    D --> E[本質的]
    E --> F[創造的解決の余地]
```

### 3. 選択肢を生み出す

```mermaid
graph TD
    A[二者択一]
    A --> B[Yes/No]
    B --> C[対立]
    
    D[複数選択肢]
    D --> E[オプションA]
    D --> F[オプションB]
    D --> G[オプションC]
    E --> H[柔軟性]
    F --> H
    G --> H
```

### 4. 客観的基準を使う

```mermaid
graph TD
    A[主観的議論]
    A --> B["高すぎる""安すぎる"]
    B --> C[平行線]
    
    D[客観的基準]
    D --> E[市場相場]
    D --> F[業界標準]
    D --> G[専門家の意見]
    E --> H[納得]
```

## 実践できること

**① 交渉前に「利害リスト」を作る**

自分と相手の本当に大切にしていることを書き出す。

**② 「なぜ？」を5回繰り返す**

「これが欲しい」→「なぜ？」→「なぜ？」...

本質的な利害が見えてくる。

**③ 3つ以上の選択肢を用意**

二者択一を避け、複数のWin-Win案を考える。

**④ 客観的基準を調査**

市場データ、業界標準などを事前に調べておく。

## まとめ

Win-Winの交渉は、**甘い理想論ではありません**。

長期的に見れば、**最も効果的な戦略**です。

相手を倒すのではなく、一緒に答えを作る。それが、持続可能な関係と真の成功を生みます。
