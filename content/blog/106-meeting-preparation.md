## はじめに

「会議が多すぎて仕事が進まない」「話し合いが長くて結論が出ない」—そんな悩みを抱える人は多いでしょう。事前準備を徹底することで、会議時間を半分に短縮し、結論を2倍速で出すことが可能になります。

## 無駄な会議の原因

### 典型的な問題

- **アジェンダなし**：何を話すか不明確
- **参加者の準備不足**：情報共有がリアルタイムで行われる
- **目的の曖昧さ**：決定か相談か報告か
- **時間の無駄**：脱線や雑談が多い

### コストの可視化

**1時間会議の実コスト：**
- 参加者5名×1時間＝5人時間
- 時給換算：5万円以上
- 月20回×12ヶ月＝1,200万円/年

## 効果的な事前準備の4要素

### 要素1：明確な目的設定

会議の前に、以下を明確にします。

**目的の分類：**
- **決定（Decision）**：合意形成が必要
- **相談（Consultation）**：意見を募る
- **報告（Report）**：情報共有のみ
- **創出（Creation）**：アイデアを出す

**目的文のテンプレート：**
```
「本日の会議では、○○について△△を決定することを目的とします。
具体的には□□と◇◇の2案から選択します。」
```

### 要素2：徹底したアジェンダ

**アジェンダの構成：**

1. **メタ情報**
   - 日時、場所、参加者
   - 目的、想定時間
   - 必要な資料

2. **議題リスト**
   ```
   1. ○○について（15分）
      - 決定事項：△△を採用するか
      - 必要な入力：□□のデータ
   
   2. □□について（20分）
      - 決定事項：◇◇のスケジュール
      - 必要な入力：予算見積もり
   ```

3. **事前準備事項**
   - 読んでおくべき資料
   - 準備しておくべきデータ
   - 考えておくべきポイント

### 要素3：事前情報共有

会議前に情報を共有し、会議は決定のみに集中します。

**情報共有の方法：**
- 事前資料の配布（24時間前までに）
- 読了確認の徹底
- 質疑応答は事前に受け付ける

**共有資料の構成：**
1. 背景と問題提起（1ページ）
2. 選択肢と各案の分析（2-3ページ）
3. 推奨案と根拠（1ページ）
4. リスクと対策（1ページ）

### 要素4：参加者の適切な選定

**必要な参加者のみ：**
- 決定権を持つ人
- 専門知識が必要な人
- 実行責任者

**不要な参加者：**
- 情報のみ必要な人（資料共有で十分）
- 代理出席（意思決定できない）
- 「念のため」参加

## 事前準備チェックリスト

### 主催者用（会議前48時間）

- [ ] 目的を明確に記述
- [ ] アジェンダを作成（時間配分付き）
- [ ] 資料を作成・添付
- [ ] 参加者を選定し招待
- [ ] 事前準備事項を明示

### 参加者用（会議前24時間）

- [ ] 資料を読了
- [ ] 疑問点をリストアップ
- [ ] 意見や提案を整理
- [ ] 必要なデータを準備
- [ ] 不参加の場合は代理を手配

## 会議中の進行法

### 時間厳守の徹底

**タイムキーパーの役割：**
- 各議題の残り時間をアナウンス
- 脱線時の注意喚起
- 時間超過時の判断（延長or次回）

### 決定フォーカス

**決定を促す質問：**
- 「では、○○案で進めますか？」
- 「反対の方はいらっしゃいますか？」
- 「決定事項として◆◆で確定でよろしいですか？」

## 応用：オンライン会議の最適化

### オンライン特有の準備

**技術的準備：**
- 接続テストの実施
- バックアップ回線の確保
- 画面共有の準備

**進行の工夫：**
- カメラオンを基本とする
- リアクション（挙手、絵文字）の活用
- ブレイクアウトルームの活用

## 注意点と落とし穴

### 過度な準備の回避

- 準備自体が目的化しない
- 完璧を求めすぎない（80点で十分）
- 参加者の負担を考慮

### 柔軟性の保持

- 重要な新情報が出た時の対応
- アジェンダの変更判断
- 継続審議の適切な使い方

## まとめ

徹底した事前準備は、会議の質を劇的に向上させます。目的の明確化、アジェンダの共有、事前情報の徹底、適切な参加者選定—この4要素を整え、効率的で成果のある会議を実現しましょう。

**次回の会議から始めるステップ：**
1. 今：次回会議のアジェンダを作成
2. 48時間前：資料を配布
3. 24時間前：参加者に準備を依頼
4. 会議当日：時間厳守で進行
5. 会議後：フォローアップ

準備を徹底し、会議を決定の場として機能させましょう。
