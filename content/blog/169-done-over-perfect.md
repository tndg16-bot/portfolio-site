## はじめに

「もっと良くしてから出そう」と思い、資料や企画を溜め込んでいませんか？完璧を求めすぎて、結果として遅れや機会損失が生じているかもしれません。「まずは60点」で世に出し、フィードバックを得て改善するアプローチで、結果的に最短で100点に近づく方法を解説します。

## 完璧主義の罠

### 完璧主義の代償

**時間の浪費：**
- 企画書：2週間かけて100点を目指す
- vs 3日で80点 → フィードバック → 2日で90点
- 結果的に後者の方が質が高い

**機会損失：**
- 準備している間に時機を逃す
- 競合に先を越される
- トレンドの変化

**フィードバックの欠如：**
- 客観的視点が入らない
- 自己満足に終わる
- ニーズとのずれ

### 60点主義のメリット

**速度：**
- 早くリリースできる
- 早くフィードバックを得られる
- 改善サイクルを回せる

**適応性：**
- 市場の反応を見て調整
- ニーズに合わせた進化
- 失敗からの早期学習

## 60点主義の実践法

### Step 1：MVP（最小限の実行可能製品）の定義

まずは「出せる最低限」を定義します。

**質問：**
- 「これがなくても出せない」要素は何か
- 「あればより良い」要素は何か
- 顧客が求める核心価値は何か

**例：**
```
【新サービス企画】

MVP（60点）：
- 核心機能のみ
- 手動対応可能な範囲
- 基本的なデザイン
- 1週間でリリース可能

追加機能（80点→100点）：
- 自動化機能
- 高度なデザイン
- 追加サービス
- リリース後の改善
```

### Step 2：期限の設定

厳しい期限を設定し、完璧主義を封じます。

**方法：**
- 希望納期の半分を期限に
- パブリックコミットメント（公言）
- タイムボックス徹底

**例：**
```
「企画書作成」
→ 本来2週間かかる
→ 期限を3日に設定
→ 3日で出せる範囲で完成
→ フィードバックを得る
→ 改善版を2日で作成
```

### Step 3：早期フィードバックの獲得

早い段階でフィードバックを得ます。

**対象：**
- 顧客
- 同僚
- メンター
- 専門家

**方法：**
- ドラフト段階で共有
- 意図的に「未完成」を見せる
- 具体的な質問をする

**質問例：**
```
「この企画について、以下の点でフィードバックをください：
1. 理解できない点
2. 興味を持てない点
3. 改善すべき点
4. 意外と良いと思った点」
```

### Step 4：イテレーティブ改善

フィードバックを反映し、繰り返し改善します。

**サイクル：**
```
V1（60点）→ フィードバック → V2（75点）
→ フィードバック → V3（85点）
→ フィードバック → V4（90点以上）
```

**各イテレーション：**
- 短い期間（数日〜1週間）
- 特定の改善点に集中
- 再フィードバック

## 応用：場面別の実践

### 文書・資料作成

**従来：**
- 1週間かけて完璧な資料

**60点主義：**
- 2日でドラフト
- 上司・同僚に確認
- 1日で修正
- 合計3日でより良い品質

### 企画・提案

**従来：**
- 完成度100%まで練る

**60点主義：**
- 核心部分のみ先行提案
- 反応を見る
- ニーズに合わせて詳細化

### 製品・サービス開発

**MVPアプローチ：**
- 核心機能のみリリース
- 早期アクセスユーザーの反応
- データに基づく改善
- 高速な進化

## 心理的安全性の確保

### 「未完成」であることを認める

**メンタルシフト：**
- 「未完成」＝「改善の余地あり」
- 「未完成」＝「早期参入」
- 「未完成」＝「適応性」

### 失敗を許容する文化

**組織的アプローチ：**
- 「ベータ版」という言葉を使う
- 「試行中」というラベル
- 失敗から学ぶ風土

## 注意点と落とし穴

### 質の最低基準

**守るべきライン：**
- 60点は「出せる」レベル
- 誤字脱字、明らかなミスは除外
- 倫理・法的問題は絶対にNG

### タイミングの見極め

**「完璧が必要な場面」：**
- 安全に関わるもの
- 法的文書
- 一度きりの機会

**「60点で十分な場面」：**
- 繰り返し改善可能なもの
- 早期反応が重要なもの
- 不確実性が高いもの

## まとめ

「まずは60点」で出す勇気は、結果的に最短で最高の成果に到達するための戦略です。完璧を求めすぎず、早期にフィードバックを得て、繰り返し改善することで、より良い成果を生み出せます。

**今週から始めるステップ：**
1. 今：溜め込んでいるものを1つ選ぶ
2. 明日：60点の基準を定める
3. 今週：公開・提出する
4. 来週：フィードバックを得て改善

完璧主義を手放し、実行と改善のサイクルを回しましょう。
