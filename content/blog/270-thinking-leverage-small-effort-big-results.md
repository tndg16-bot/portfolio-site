## はじめに

「頑張っているのに、
成果が出ない...」

そんな経験、ありませんか？

実は、問題は「頑張り足りない」ことではなく、
**「どこに力を入れているか」**にあります。

物理でいう「レバー」の原理。
小さな力でも、
支点の選び方で大きなものを動かせます。

思考にも同じ原理が働きます。

---

## レバレッジとは何か

### 物理的な理解

```mermaid
graph LR
    A[力点<br/>小さな力] --> B[支点<br/>適切な位置]
    B --> C[作用点<br/>大きな成果]
```

**「力を入れる場所」と「支点」の選び方**で、
同じ努力でも全く異なる結果が生まれます。

### 思考への応用

```mermaid
graph TD
    A[あなたの努力] --> B{支点は？}
    B --> C[非効率<br/>力任せ]
    B --> D[高レバレッジ<br/>小さな力で大きな成果]
```

## 高レバレッジ活動の見つけ方

### 1. 80/20の法則を意識する

```mermaid
pie title "成果の源泉"
    "高レバレッジ活動 20%" : 80
    "その他の活動 80%" : 20
```

**20%の活動が80%の成果を生む**。
その20%を見つけることが鍵です。

### 2. 「複利効果」を考える

```mermaid
graph TD
    A[一回きりの活動] --> B[一時的な成果]
    C[複利効果のある活動] --> D[継続的な成果]
    D --> E[さらに大きな成果]
    E --> F[指数関数的成長]
```

高レバレッジな活動の特徴：
- 一度やれば繰り返し使える
- 時間が経つほど価値が増す
- 他の活動を加速させる

### 3. 「ボトルネック」を解消する

```mermaid
graph LR
    A[タスクA] --> B[タスクB<br/>ボトルネック]
    B --> C[タスクC]
    B --> D[タスクD]
    B --> E[タスクE]
    
    F[Bを改善] --> G[全体が加速]
```

全体の流れを遅らせている
**一つの障害を取り除く**ことで、
全体が動き出します。

## 職場でのレバレッジ活用

### 会議の例

```mermaid
graph TD
    A[従来の会議] --> B[1時間×10人 = 10人時]
    A --> C[議論が散漫]
    A --> D[結論が出ない]
    
    E[高レバレッジな会議] --> F[事前に議題共有]
    F --> G[30分×10人 = 5人時]
    G --> H[明確な意思決定]
    H --> I[実行に移せる]
```

**「会議の仕組み」を変える**だけで、
全員の時間が解放されます。

### 人間関係の例

```mermaid
graph TD
    A[高レバレッジな人] --> B[キーパーソンとの<br/>信頼関係構築]
    B --> C[情報の早期入手]
    B --> D[決裁の迅速化]
    B --> E[チームの巻き込み]
```

全員と浅く関わるより、
**重要な人と深く信頼関係を築く**方が、
遥かに大きな影響力を持ちます。

## レバレッジ診断フレームワーク

### 4つの質問

```mermaid
graph TD
    A[この活動は...]
    A --> B[一度やれば<br/>繰り返し使えるか？]
    A --> C[他の活動を<br/>加速させるか？]
    A --> D[時間が経つほど<br/>価値が増すか？]
    A --> E[やらないと<br/>他が止まるか？]
```

4つとも「Yes」なら、
**最優先で取り組むべき高レバレッジ活動**です。

### 自分の活動の棚卸し

```mermaid
graph LR
    subgraph 高レバレッジ
        A[システム構築]
        B[人材育成]
        C[関係構築]
    end
    
    subgraph 低レバレッジ
        D[定型作業]
        E[ミーティング参加]
        F[メール対応]
    end
```

## 実践できること

**① 今週の活動を「レバレッジ度」で分類**

高レバレッジ・中・低の3つに分け、
時間配分を見直す。

**② 「もしこれを改善したら？」の問い**

今の課題の中で、
「これを改善したら全体が楽になる」
ものを1つ選ぶ。

**③ 「自動化・委任化」の検討**

低レバレッジな作業を
どう自動化・委任できるか考える。

**④ 朝の「高レバレッジ時間」**

1日の始まりに、
最もレバレッジの高い活動を
1つだけやる。

## まとめ

レバレッジ思考は、
**「もっと頑張る」ことではなく、
「もっと賢く働く」**ことです。

小さな力で大きな成果を出す。
それが可能なのは、
**支点を正しく選ぶ**からです。

忙しさに追われて、
低レバレッジな活動に没頭していませんか？

立ち止まって、
**「どこに力を入れるべきか」**
を問い直す。

その一問が、
あなたの成果を
劇的に変えるかもしれません。
