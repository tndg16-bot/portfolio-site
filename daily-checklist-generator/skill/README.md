# Daily Checklist Generator

デイリーノートから未完了タスクを抽出し、優先順位付けしたチェックリストを自動生成します。

## 特徴

✅ **自動タスク抽出** - Obsidianのデイリーノートから `- [ ]` 形式のタスクを自動検出
✅ **スマート優先順位** - 緊急度と重要度に基づいてタスクを自動ソート
✅ **朝の通知統合** - morning-secretaryと連携して朝の通知に表示
✅ **簡単設定** - `config.json`でカスタマイズ可能
✅ **エラーハンドリング** - ファイルがない場合やエラーにも安全に対応

## クイックスタート

### 1. 設定ファイルの編集

`config.json`を編集して、デイリーノートのパスを設定します：

```json
{
  "dailyNotesPath": "D:/AntigravityVault/daily",
  "priorityMarkers": ["!!!", "!!", "!"],
  "dueDatePatterns": ["@due", "@today", "@tomorrow"],
  "maxTasks": 20,
  "timezone": "Asia/Tokyo"
}
```

### 2. デイリーノートにタスクを追加

Obsidianのデイリーノートでタスクを記述します：

```markdown
- [ ] 報告書の作成 !!! @today
- [ ] 会議の準備 !! @tomorrow
- [ ] メールチェック
- [ ] コードレビュー ! @due
```

### 3. チェックリストを生成

スキルを実行します：

```
daily-checklist-generator
```

## 使い方

### 基本的な使用

```
daily-checklist-generator
```

### カスタムパスを指定

```
daily-checklist-generator --path "C:/path/to/notes"
```

## 優先順位の仕組み

### 緊急度 (Urgency)
- 🔴 **高 (3点)**: `@due`, `@today` - 今日が期限のタスク
- 🟡 **中 (2点)**: `@tomorrow` - 明日が期限のタスク
- 🟢 **低 (1点)**: 期限の指定なし

### 重要度 (Importance)
- 🔴 **高 (3点)**: `!!!` - 非常に重要
- 🟡 **中 (2点)**: `!!` - 重要
- 🟢 **低 (1.5点)**: `!` - 優先度低め
- ⚪ **なし (1点)**: マーカーなし

### スコア計算

**スコア = 緊急度 × 重要度**

例：
- `!!! + @due` = 3 × 3 = **9** (最高優先)
- `! + @today` = 3 × 1.5 = **4.5**
- `!!!` = 1 × 3 = **3**
- `! + @tomorrow` = 2 × 1.5 = **3**
- マーカーなし = 1 × 1 = **1** (最低優先)

## 出力例

```

*合計: 5件（高優先: 2, 中: 1, 低: 2）*

🔴 1. 報告書の作成 !!! @today
🔴 2. コードレビュー ! @due
🟡 3. 会議の準備 !! @tomorrow
🟢 4. メールチェック
🟢 5. ドキュメント更新
```

## morning-secretary との統合

朝の通知にチェックリストを含めたい場合、`morning-secretary`スキルと一緒に使用します：

```javascript
const checklist = require('./daily-checklist-generator');

// チェックリストを生成
const result = checklist.generateChecklist(config.dailyNotesPath);
const formatted = checklist.formatChecklist(result);

// 朝のメッセージに追加
morningMessage += '\n\n' + formatted;
```

## タスクのフォーマット

デイリーノートでは以下の形式でタスクを記述してください：

### 基本的なタスク
```markdown
- [ ] タスク名
```

### 優先度マーカー付き
```markdown
- [ ] ! 優先度低め
- [ ] !! 優先度中
- [ ] !!! 緊急
```

### 期限付き
```markdown
- [ ] タスク名 @today      (今日が期限)
- [ ] タスク名 @tomorrow   (明日が期限)
- [ ] タスク名 @due        (期限あり)
```

### 組み合わせ
```markdown
- [ ] !!! 緊急タスク @today
- [ ] !! 重要なタスク @tomorrow
- [ ] ! いつかやるタスク
```

## 設定オプション

| オプション | 説明 | デフォルト |
|----------|------|-----------|
| `dailyNotesPath` | デイリーノートのディレクトリパス | `./daily` |
| `priorityMarkers` | 優先度マーカーの配列 | `["!!!", "!!", "!"]` |
| `dueDatePatterns` | 期限を示すパターン | `["@due", "@today", "@tomorrow"]` |
| `maxTasks` | 表示する最大タスク数 | `20` |
| `timezone` | タイムゾーン | `Asia/Tokyo` |

## エラーハンドリング

スキルは以下の状況に自動的に対応します：

- ✅ **ディレクトリが見つからない**: 「デイリーノートが見つかりません」というメッセージを表示
- ✅ **タスクがない**: 「未完了タスクが見つかりません」というメッセージを表示
- ✅ **ファイル読み込みエラー**: エラーをログして他のファイルを処理
- ✅ **設定ファイルがない**: デフォルト設定を使用

## パフォーマンス

- ⚡ **高速**: 30ファイルを1秒未満でスキャン
- 💾 **低メモリ**: ストリーミング読み込みで効率的
- 🔧 **柔軟**: 最大タスク数で出力を制御可能

## トラブルシューティング

### 「デイリーノートが見つかりません」と表示される

`config.json`の `dailyNotesPath` が正しいか確認してください。

```json
{
  "dailyNotesPath": "D:/AntigravityVault/daily"  // ← 確認
}
```

### タスクが抽出されない

以下を確認してください：
1. タスクが `- [ ]` 形式であること
2. 拡張子が `.md` であること
3. ファイルが指定したディレクトリにあること

### 優先順位がおかしい

以下を確認してください：
1. 優先度マーカーが `config.json` の設定と一致しているか
2. 期限パターンが正しく記述されているか
